# Motion vocabulary sources

Use these to put a name to a motion you like, then record it in `taxonomy/motion.yaml` in your private taste data with the post that showed it.

- **One Shot Prompts** (https://oneshotprompts.com): 923 named motion techniques, each with a live example and a ready prompt. Announced at https://x.com/cherry_mx_reds/status/2112917548891345031. Its licence is unverified: link to techniques and cite them, and don't copy the examples in bulk.
- **tasteskill's own motion library**: `skills/taste-skill/references/motion.md` and `library/` (step 9).

Record a named technique as:

```yaml
- name: staggered fade-through        # the vocabulary name
  source: https://oneshotprompts.com/...
  seen_in: https://x.com/<author>/status/<id>   # the bookmark that shows it
  use_for: list entrance, ≤150 ms total
  avoid: long lists, layout moves
```
